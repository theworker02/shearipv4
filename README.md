# shearipv4

Shear HTML/Markdown ipv4 fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/shearipv4/

## Install / run

```bash
git clone https://github.com/theworker02/shearipv4.git
cd shearipv4
node src/cli.js
node --test
```
